# docs/legal: 공개 페이지 초안 (잼얘좀)

서버가 `GET /privacy`, `GET /terms`, `GET /account-deletion`, `GET /support`로 서빙하는 한국어 HTML 본문 조각의 원본이다. 작성자는 에이전트이고, 사용자가 읽고 승인하기 전에는 공개하지 않는다. 이 초안은 법률 자문이 아니며 법령 준수를 보장하지 않는다.

| 파일 | 내용 |
|---|---|
| `privacy.ko.html` | 개인정보 처리방침 |
| `terms.ko.html` | 이용약관 (첫 줄 `<!-- terms-version: v1 -->`) |
| `account-deletion.ko.html` | 계정 삭제 안내 (앱 내 경로 + 이메일 요청 경로) |
| `support.ko.html` | 문의하기 (연락처, 24시간 신고 응답, FAQ) |

HTML은 `<html>`, `<head>`, 스크립트, 외부 리소스가 없는 본문 조각이다. 페이지 사이 링크는 같은 도메인 상대 경로(`/terms`, `/privacy`, `/account-deletion`, `/support`)만 쓴다.

초안 근거의 출처 표기:

- facts: 코드 사실 확인 `m18-facts-20261007-133012.md` (번호는 그 파일의 항목 번호)
- R8, R9: `requirements-20261007-133012.md`의 사용자 결정
- 개정 지시: ultrawork 20261007-133012의 초안 개정 지시 (웹 삭제 요청의 본인 확인 방식 등)

## 1. 치환 자리표시자

허용되는 자리표시자는 아래 세 개뿐이다. 서버가 환경변수 값으로 HTML 이스케이프해서 치환한다. 실제 값은 이 저장소에 쓰지 않는다.

| 자리표시자 | 서버 환경변수 | 쓰이는 곳 | 필수 |
|---|---|---|---|
| `{{OPERATOR_NAME}}` | `JAMYE_LEGAL_OPERATOR_NAME` | 네 페이지 모두 | 필수 |
| `{{CONTACT_EMAIL}}` | `JAMYE_LEGAL_CONTACT_EMAIL` | 네 페이지 모두 (mailto 링크 포함) | 필수 |
| `{{OPERATOR_ADDRESS}}` | `JAMYE_LEGAL_OPERATOR_ADDRESS` | `privacy.ko.html` 문의처 한 줄에만 | 서버 계약상 선택 |

`{{OPERATOR_ADDRESS}}`는 `privacy.ko.html`의 `<!-- address:start -->` / `<!-- address:end -->` 마커 사이에만 있다. 마커는 그대로 둔다. 세 값은 사용자가 홈랩 시크릿으로 서버 환경변수에 주입한다(남은 사용자 항목 1).

## 2. 시행일 줄

네 파일 모두 제목 아래에 같은 형식의 일반 텍스트 한 줄이 있다. 자리표시자도 환경변수도 아니다.

```
시행일: YYYY-MM-DD (사용자 확정 필요)
```

사용자가 승인하는 날 네 파일에서 `YYYY-MM-DD (사용자 확정 필요)`를 실제 날짜로 바꾼다 (예: `시행일: 2026-11-01`). 문구 `(사용자 확정 필요)`는 함께 지운다. 첫 공개본의 시행일은 2026-10-09다(사용자 확정, 법적 페이지 값이 운영 서버에 들어간 날).

`terms.ko.html`의 `<!-- terms-version: v1 -->`는 앱의 `TERMS_VERSION`과 같은 값이다. 약관 내용을 실질적으로 바꿀 때만 v2로 올리고, 앱 상수도 함께 올려야 앱이 다시 동의를 받는다.

## 4. 사실 근거 (초안이 의존하는 동작)

- 로그인 제공자 요청 항목: Kakao `profile_nickname profile_image`, Google `openid profile`, Apple 이름만. 이메일은 어디서도 요청하거나 저장하지 않는다. 제공자 토큰은 저장하지 않는다. 저장: 닉네임, 프로필 사진 주소(https), 로그인 연결(제공자, 제공자 계정 ID) (facts 1, 2).
- Apple 이름은 1~64자면 기본 닉네임으로 쓰고, 아니면 "Apple"과 숫자 6자리. 프로필 사진 없음 (facts 2).
- 계정 삭제: 시작 즉시 세션 폐기, 푸시 비활성, 그룹 제외, 30일 유예 동안 "탈퇴한 사용자"로 표시, 유예 중 같은 provider 로그인으로 복구, 만료 후 purge. 그룹 소유자는 소유권 이전 필요 (facts 3).
- 로그: 요청 번호, 요청 방식, 경로만 기록하고 클라이언트 IP는 기록하지 않는다. 속도 제한 키는 프록시가 보는 연결 주소를 SHA-256으로 해시해 Redis에 두고 제한 창과 함께 만료한다. 앱에는 오류 수집, 분석, 광고 SDK가 없다 (facts 4).
- 앱 밖으로 나가는 정보: Expo 푸시 토큰(Expo), Android의 FCM(Firebase, 푸시 전용, 분석 없음), 서버에서 Expo Push API 호출, Kakao/Google은 인증 브라우저, Apple은 expo-apple-authentication (facts 4).
- 초대는 앱에서 항상 7일 만료로 만들고, 그룹 정원은 12명이다 (facts 5). 지원 페이지 FAQ가 이 값을 쓴다.
- 푸시 미리보기는 모든 계층에서 기본 꺼짐이고 "메시지 미리보기" 스위치로 켠다. 기본 본문은 "새 메시지가 도착했습니다." (facts 7).
- 필터: 서버가 채팅 메시지와 주제 공지를 받을 때 운영자 목록의 심한 욕설과 혐오 표현을 `***`로 바꾼다. 메시지는 그대로 전송된다 (R8).
- 약관 동의: 앱 로컬 저장만 하고 서버 기록은 없다.
- 미디어는 자체 호스팅 오브젝트 스토리지, API 서버도 자체 호스팅.

task-qa-verify-safety와 task-docs-final이 구현된 동작과 다시 대조한다. 어긋나면 이 문서를 고치고 사용자가 다시 승인한다.

## 6. 남은 사용자 항목

1. **운영자 정보**: 운영자 이름, 문의 이메일, 주소. 세 값을 홈랩 시크릿으로 `JAMYE_LEGAL_OPERATOR_NAME`, `JAMYE_LEGAL_CONTACT_EMAIL`, `JAMYE_LEGAL_OPERATOR_ADDRESS`에 주입한다. 완료(2026-10-09, 주소 포함).
2. **시행일**: 완료. 네 파일의 시행일은 2026-10-09다.
3. **법률 검토**: 아래 항목을 포함해 공개 전에 검토한다.
   - 한국 개인정보 보호법 기재 항목(개인정보 보호책임자 표기, 위탁/제3자 제공 구분, 국외 이전 고지)과 국외 처리 문구 (원래 질문 6)
   - 만 14세 미만 확인 절차: 현재 나이 확인은 없고 약관 동의와 문구뿐이다. 약관은 만 14세 미만 이용 불가이고 스토어 등급은 16+, Play 대상 연령은 16세 이상으로 정했다(R9(c)). 이 차이가 충분한지 (원래 질문 10)
   - 약관의 준거법과 책임 조항 (원래 질문 14)
   - 백업과 정지 기록 보관 기간 표기, 신고 기록 1년의 기산점
   - 전 세계 배포(R9(b))에 따른 해외 이용자 대상 고지 범위

참고(사용자 결정 아님): 웹 삭제 요청은 운영자가 확인 후 admin 명령 `jamye-server-admin accounts delete`로 처리한다(task-20c, 절차는 `docs/operations/moderation.md`).
