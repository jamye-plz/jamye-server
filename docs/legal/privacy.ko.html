잼얘좀 개인정보 처리방침

시행일: 2026-10-09

{{OPERATOR_NAME}}(이하 "운영자")는 모바일 앱 "잼얘좀"(이하 "서비스")을 운영하면서 필요한 최소한의 개인정보만 처리합니다. 이 문서는 어떤 정보를 어떤 목적으로 어디에 쓰고, 얼마나 보관하며, 어떻게 삭제하는지 설명합니다.

1. 처리하는 정보

가. 로그인과 프로필

  • 로그인 방식(Kakao, Google, Apple)과 해당 서비스가 부여하는 계정 고유 식별자
  • 서비스가 로그인 제공자에게 요청하는 정보는 다음뿐입니다. Kakao는 닉네임과 프로필 이미지, Google은 이름과 프로필 사진, Apple은 이름입니다. Apple 이름은 로그인할 때 제공에 동의한 경우에만 받습니다.
  • 서버에 저장하는 프로필 정보는 닉네임과 프로필 사진 주소(이미지 URL)입니다. 닉네임은 Kakao 닉네임, Google 이름 또는 Apple 이름을 처음 값으로 쓰며(Apple에서 이름을 받지 못했거나 너무 길면 "Apple"과 숫자 6자리로 자동으로 만든 이름을 씁니다), 이후 앱에서 바꿀 수 있습니다. Apple 로그인은 프로필 사진을 받지 않습니다. 내가 직접 올린 프로필 사진도 저장합니다.
  • 이메일 주소는 어떤 로그인 방식에서도 요청하거나 받거나 저장하지 않습니다. 전화번호도 처리하지 않습니다.
  • 로그인 제공자가 발급하는 접근 토큰 등 제공자의 로그인 토큰은 서버에 저장하지 않습니다.

나. 대화와 모임

  • 가입한 그룹과 주제, 내가 만든 초대 링크·초대 코드
  • 내가 보낸 글, 사진, 동영상, 음성 메시지와 그 첨부 파일
  • 대화 읽음 위치, 알림 목록

다. 푸시 알림

  • 알림을 허용한 기기마다 앱이 무작위로 만든 설치 식별자, 플랫폼(iOS 또는 Android), Expo 푸시 토큰, 알림 등록 환경, 알림 미리보기 설정, 마지막으로 확인된 시각과 알림이 해제된 시각을 저장합니다.
  • 기기 모델, 운영체제 버전, 사용자 에이전트, IP 주소는 저장하지 않습니다.
  • 알림 미리보기는 기본적으로 꺼져 있습니다. 앱에서 "메시지 미리보기"를 켜기 전에는 알림에 "새 메시지가 도착했습니다."와 같은 일반 문구만 보내고 메시지 내용은 보내지 않습니다.

라. 신고, 차단, 이용 제한

  • 신고 기록: 신고한 사람, 신고 대상(메시지 또는 사용자), 사유, 신고 시점의 메시지 내용 사본(필터로 가려진 상태의 본문, 최대 4,000자, 첨부 파일 참조 포함), 처리 상태와 처리 시각
  • 내가 차단한 사용자 목록
  • 운영자가 계정을 정지한 경우 정지 시각과 사유

마. 접속과 보안

  • 로그인 유지를 위한 토큰(서버에는 원문이 아닌 해시값만 저장합니다)과 만료 시각
  • 요청 횟수 제한: 로그인, 초대, 사진 조회 등의 요청 횟수를 제한하기 위해, 서버가 보는 연결 주소(서버 앞단 프록시의 주소이며 이용자의 원래 IP 주소를 따로 읽지 않습니다)를 해시(SHA-256)한 값만 임시 저장소에 둡니다. 이 값은 제한 시간이 끝나면 사라집니다.
  • 운영 로그: 장애와 보안 문제를 확인하기 위해 요청 시각, 요청 번호, 요청 방식, 요청 경로, 오류 정보 등을 기록합니다. 이용자의 IP 주소는 운영 로그에 기록하지 않습니다.
  • 앱에는 광고, 분석, 오류 수집용 SDK가 없습니다.

바. 기기 권한

앱은 사진·동영상을 고르거나 음성 메시지를 녹음할 때에만 사진 보관함과 마이크 권한을 요청하며, 내가 메시지로 보내거나 프로필 사진으로 올린 파일만 서버로 전송됩니다. 약관 동의 여부는 앱이 기기 안에만 저장하고 서버로 보내지 않습니다. 광고용 식별자와 위치 정보는 처리하지 않습니다.

2. 처리 목적

  • 로그인과 계정 식별, 로그인 유지
  • 초대받은 그룹과 주제에서 메시지와 파일을 주고받는 서비스 제공
  • 새 메시지와 주제를 알리는 푸시 알림 전달
  • 신고 검토, 부적절한 콘텐츠 삭제, 계정 정지 등 서비스 안전 관리
  • 요청 남용 방지와 장애·보안 점검
  • 문의와 계정 삭제 요청 응대

수집한 정보를 광고나 마케팅에 쓰지 않으며 판매하지 않습니다.

3. 함께 쓰는 외부 서비스와 저장 위치

  • Kakao: Kakao 계정으로 로그인할 때 Kakao가 본인 확인을 하고 계정 식별자, 닉네임, 프로필 이미지를 서비스에 전달합니다.
  • Google: Google 계정으로 로그인할 때 같은 방식으로 계정 식별자, 이름, 프로필 사진을 전달합니다.
  • Apple: iOS에서 Apple로 로그인할 때 Apple이 본인 확인을 하고 계정 식별자와, 내가 제공에 동의한 경우 이름을 전달합니다. 이메일은 요청하지 않습니다. 계정을 삭제하면 서비스는 Apple에 로그인 연결 해제(토큰 철회)를 요청합니다.
  • Expo 푸시 서비스(Expo): 푸시 알림을 보내기 위해 Expo 푸시 토큰과 알림 제목·내용이 서버에서 Expo의 푸시 서비스로 전달되며, 알림은 iOS에서는 Apple의 알림 서비스를, Android에서는 Google의 알림 서비스를 거쳐 기기에 도착합니다. 알림 미리보기를 켠 경우 메시지 일부가 알림 내용에 들어갈 수 있습니다.
  • Firebase Cloud Messaging(Google): Android 기기에서 푸시 알림을 받는 데에만 쓰며, 분석이나 광고 목적으로는 쓰지 않습니다.
  • 미디어 저장소: 사진, 동영상, 음성, 프로필 사진 파일은 운영자가 직접 운영하는 오브젝트 스토리지(자체 호스팅)에 저장됩니다. API 서버와 데이터베이스도 운영자가 직접 운영합니다.

Kakao, Google(Firebase 포함), Apple, Expo는 각자의 약관과 개인정보 처리방침에 따라 정보를 처리하며, Google, Apple, Expo 등 해외 사업자를 통해 정보가 국외에서 처리될 수 있습니다. 이들 외에 운영자는 정보를 제3자에게 제공하지 않습니다. 다만 법령에 근거한 적법한 요청이 있을 때는 필요한 범위에서 협조할 수 있습니다. 운영자만 신고 처리를 위해 신고된 메시지 내용과 첨부 파일을 확인할 수 있습니다.

4. 보관과 삭제

  • 계정과 대화 정보: 계정을 유지하는 동안 보관합니다. 내가 보낸 메시지는 직접 삭제할 수 있고, 프로필 사진은 교체하거나 해제하면 저장소에서 삭제됩니다.
  • 계정 삭제: 앱의 "계정 > 계정 삭제"로 삭제를 시작하면 바로 로그아웃되고, 모든 그룹에서 제외되며, 푸시 알림이 중단됩니다. 이 시점부터 30일 동안은 같은 로그인 방식으로 다시 로그인해 복구할 수 있고, 복구 기간에도 다른 사람에게는 내 이름이 "탈퇴한 사용자"로 표시됩니다. 그룹의 소유자는 먼저 소유권을 다른 멤버에게 넘겨야 삭제할 수 있습니다.
  • 30일 뒤 삭제되는 정보: 30일이 지나면 되돌릴 수 없으며 아래 정보를 삭제합니다.
    • 로그인 연결 정보(Kakao, Google, Apple 계정과의 연결)와 로그인 세션
    • 닉네임, 프로필 사진 주소, 계정 정보 자체
    • 내가 올린 프로필 사진 파일과 메시지에 붙이지 않고 남은 업로드 파일(저장소에서 삭제하도록 요청합니다)
    • 그룹 가입 정보
    • 푸시 토큰과 기기 설치 정보, 알림과 읽음 기록
    • 내가 만든 초대 링크와 초대 코드
    • 서버 내부의 이벤트·알림 전달 기록에 들어 있던 내 식별자와 프로필 정보
    • Apple로 로그인한 경우 Apple에 로그인 연결 해제 요청
  • 삭제 후 남는 정보: 그룹 대화에 이미 보낸 메시지와 주제, 메시지에 붙인 사진·동영상·음성 파일은 그룹의 대화 기록으로 남습니다. 작성자는 이름도 사진도 없는 익명의 "탈퇴한 사용자"로 바뀌어 나의 계정이나 이름과 연결되지 않으며, 같은 사람이 쓴 글은 같은 "탈퇴한 사용자" 아래 묶여 보일 수 있습니다. 메시지 본문에 직접 적은 개인정보는 남을 수 있으니, 남기고 싶지 않은 메시지는 계정을 삭제하기 전에 직접 삭제해 주세요.
  • 신고 기록: 분쟁 대응과 재발 방지를 위한 증빙으로 처리가 끝난 날부터 1년간 보관한 뒤 운영자가 삭제합니다. 다른 사람이 나를 신고한 기록도 같은 기준으로 보관합니다.
  • 요청 횟수 제한 값: 연결 주소의 해시값은 제한 시간이 끝나면 사라집니다.
  • 운영 로그: 14일 동안 보관한 뒤 삭제합니다.
  • 백업: 서버 점검이나 업데이트 전에 만드는 백업에는 삭제 이전의 정보가 일정 기간 남아 있을 수 있으며, 필요 없어지면 폐기합니다.

5. 이용자의 권리

앱에서 프로필 사진을 바꾸고, 내가 보낸 메시지를 삭제하고, 계정을 삭제할 수 있습니다. 내 정보의 열람, 정정, 삭제, 처리 정지를 원하면 아래 문의처로 요청해 주세요. 본인 확인 후 합리적인 기간 안에 답변하고 처리합니다. 웹에서 계정 삭제를 요청하는 방법은 계정 삭제 안내에 있습니다.

6. 만 14세 미만 아동

서비스는 만 14세 미만을 대상으로 하지 않으며 만 14세 미만의 이용을 허용하지 않습니다. 만 14세 미만 아동의 정보를 처리하고 있다는 사실을 알게 되면 해당 계정과 정보를 지체 없이 삭제합니다. 자녀가 가입했다고 생각되면 아래 문의처로 알려 주세요.

7. 안전 조치

앱과 서버 사이의 통신은 HTTPS로 암호화되고, 로그인 유지 토큰은 해시로만 저장하며, 운영자 외에는 신고 내용과 서버 데이터에 접근할 수 없도록 관리합니다. 다만 어떤 시스템도 완전한 보안을 보장할 수는 없으므로 사고가 생기면 가능한 한 빨리 알리고 조치하겠습니다.
